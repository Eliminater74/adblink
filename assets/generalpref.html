Specify directories:
Pull directory. A global location where files "pulled" from the selected device go. This can be overridden at the device-level in the device's record.

APK directory. The default location where adblink looks for APKs to install

Backup directory. The default location where backups are saved. Restore looks here as well.

Choose terminal type:

macOS: iterm2 or Terminal

Linux: Gnome terminal, XFCE4 terminal and Konsole.

Windows: N/A

If you have questions or comments, please email jocala@jocala.com or visit one of the forums listed at jocala.com. adbLink produces a log file, adblink.log, with each run. Include it in your email or post if you're having problems.
